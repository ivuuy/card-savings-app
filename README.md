# 小卡攒钱记

韩系薄荷灰风的攒钱挑战 App 前端原型，使用 uniapp + Vue3 页面结构实现。

## 已实现

- 15 个页面：包含账单详情、周期历史、我的心愿、备份与恢复、自由配色
- 首页「配色」和「我的」专属入口：10 组灵感配色，主色/背景/卡片分别自选，完整色相、饱和度与明度调节，支持 HEX 色号；实时预览、保存、恢复薄荷灰，配色随本地数据和备份保留
- 深浅主题自动调整文字和按钮文字颜色
- 统一自定义底部 Tab Bar
- 预算进度、80% 提醒、超支提醒
- 演示账单按交易编号去重；收入、退款、内部转账分开计算；搜索、月份/类型筛选、加载更多、详情纠正和排除
- 宝石余额、负数冻结、宝石记录
- 成员卡稀有度、锁定、冷却、解锁提示
- 真实日期、本地持久保存、周/月补结算、防重复奖惩与预算快照；新预算从下周期生效
- 低消费日挑战：完整且已结束的日期才能领取，每天一次；成功 +5 宝石，并恢复一张冷却小卡
- 成员预览、心愿成员、专属卡面、收藏日期；解锁同时消耗宝石和成功任务获得的资格
- 小卡默认显示现有卡背，点击原地翻到人物正面，再点翻回；首页、收藏和详情共用翻牌交互，详情入口独立保留
- 人物照片按 2:3 竖幅裁切并保存；图片读取失败可在详情中更换
- 心愿目标、净收支进度、昵称、可撤销重置、完整 JSON 备份导出/恢复
- 持久预算封面：网页端居中裁为 16:9 并压缩保存；设置页图片暂存，保存后生效
- 页面预算预警及可选系统通知；网页或 App 关闭后不保证后台通知

## 规则与边界

- **暂不接真实支付账单**，同步只使用明确标注的演示数据。示例覆盖完整到昨天，今天未结束，不可提前领取低消费奖励。
- 周成功 +10、月成功 +50，各获得 1 次解锁资格；周/月失败分别扣 20，可选允许负数或最低到零，不叠加连续失败倍率。
- 月任务同时检查月总额和月内每个周区间；跨月周只计本月日期，沿用该周完整额度。规则页展示同样说明。
- 退款按到账日期抵扣，关联原支出，累计不超过原消费；内部转账不计收入或支出。
- 已结算周期和已领取挑战奖励的日期锁定账单；周期结果保留当时的预算和消费快照。
- 本地存储以 `idol-budget-v2` 为键。损坏数据不会被自动覆盖；保存失败的预算、同步和奖惩操作会撤销并提示。
- 网页可下载/选择 JSON 备份文件；其他端可复制、粘贴完整备份文本。本地图片路径在换设备后可能需要重新选择。
- 默认卡背为文具风收藏卡（花朵、爱心与星光图案）；人物正面支持本地照片，尚未生成的原创人物照片显示明确空态。未使用真实艺人照片。

## 运行方式

本项目是 HBuilderX/uniapp 标准结构，可以直接用 HBuilderX 打开当前目录，使用 Vue3 编译器运行到浏览器、模拟器或小程序。

当前 Mac 已安装 HBuilderX，可以双击项目中的 `preview.command` 启动网页预览，不需要另外安装 npm 依赖。启动后访问：

http://localhost:8081/#/

预览期间请保留启动的终端窗口。关闭终端或按 Ctrl+C 会停止服务；再次访问前需要重新启动。脚本使用 HBuilderX 自带的 Vue3 编译器和依赖，不修改 HBuilderX 文件。

如果本机安装了 uniapp CLI 依赖，也可以执行：

```bash
npm install
npm run dev:h5
```

CLI 模式需要项目本地安装相互兼容的 uniapp Vue3、Vite 和 Vue 依赖；`preview.command` 使用电脑上已有的配套编译环境。

## 视觉规范

- 默认浅灰白底色、低饱和薄荷绿与深灰文字；用户可自由搭配全色系，保留轻边框、圆角和低强度阴影。
- `styles/theme.css` 集中管理全局颜色、间距、表单及按钮；所有 15 个页面共用主题。
- 手机优先布局；桌面内容和导航居中，最大宽度 520px，首页两侧保留留白，保留底部安全区。
- `static/icons` 使用 Tabler Icons 3.35.0 的 MIT 授权 SVG，离线可用，许可证随资源保留。
- 小卡采用拍立得边框与文具风卡背，用户上传的专属照片显示在翻转后的人物正面。
